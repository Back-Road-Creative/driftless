itself rather than importing this. ``page`` names the current page — the trail's last, unlinked crumb; ``as_of`` is carried onto the project-hub link only when the caller has one to carry, so a page with no as_of in scope links the hub bare rather than raising on an undefined name. #} {% macro trail(project, page, as_of=None) %}

{% endmacro %} {# The two-crumb trail, for a page that hangs off the dashboard directly rather than off a project — a business surface has no project to sit under.
